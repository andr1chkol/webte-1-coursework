- **Autor:** Andrii Lazaresku

## O projekte

Projekt je osobná webová vizitka vytvorená pomocou HTML5, CSS a JavaScriptu. Obsahuje profil, životopis, interaktívne pracovné prostredie, týždenný rozvrh a mapu dôležitých miest. Web má jednotný responzívny dizajn a je prispôsobený pre desktopové aj mobilné zariadenia.

## Obsah webu

- `index.html` - osobný profil a základné informácie,
- `pages/cv.html` - životopis s tlačovým štýlom,
- `pages/workspace.html` - pracovné prostredie s piatimi CSS hotspotmi,
- `pages/schedule.html` - interaktívny rozvrh, filtre a priebeh semestra,
- `pages/map.html` - Leaflet mapa s vlastnými bodmi a výpočtom vzdialenosti.

## Použité technológie

- HTML5,
- CSS3,
- JavaScript,
- Leaflet 1.9.4,
- OpenStreetMap.
